# Crane Wayfarer

The fitted player uses a head and neck excerpt of the MakeHuman standard base mesh. The source OBJ explicitly releases the geometry under CC0. The original authors are Data Collection AB, Joel Palmius and Jonas Hauquier. The fitting retains the facial topology, projects a new diffuse texture and assigns hair and skin to separate surfaces. [MakeHuman source mesh and license notice](https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj)

The two original ImageGen texture sources are a straight-on, neutral-light portrait of a fictional adult Chinese swordswoman, and a flat indigo silk weave with an embroidered egret, cloud scrolls and reed grass. The crane is mapped across the back yoke of the playable model. The fitting builds the cross collar, split skirt, sleeves, sash, jade fastening, hair knot and pin around the local combat skeleton. The boots, hands, trouser base, sword and scabbard use the project's existing assets.
