# Lotus leaf

`lotus-leaf.jpg` is an original generated albedo. The garden maps the central attachment point across seven radial subdivisions on each cupped leaf. The lotus stalks, petals, seed receptacles, bridge and stone facing are modeled in the project. The runtime supplies light, water reflections and moving ripples. [Garden in Unreal](../../../docs/runtime/moon-water/)

The ImageGen brief requested a tightly cropped, orthographic upper surface of a mature sacred lotus leaf in muted jade and sage, with a central peltate attachment, fine branching veins, waxy stippling and diffuse illumination.

The petals use the original ImageGen albedo in `lotus-petal.jpg`. The brief requested a tightly cropped upper petal surface with fine veins running from a warm ivory base towards the shell-pink tip. Each three-dimensional petal samples that gradient from base to tip.
