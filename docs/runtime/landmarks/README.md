# Combat viewpoints on the RTX 5080

These unretouched 2560×1440 images show the opening exchange in the production browser build on Windows Edge. The run entered all three fights from the menu in a single session, moved forward, attacked, dodged and parried. The six-second samples averaged 40.0, 42.9 and 41.1 frames per second respectively. Long frame intervals persist. The Unreal project has no verified playable level yet.
