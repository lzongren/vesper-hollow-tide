The Windows production browser build used the RTX 5080 at 2560×1440. The silent video contains 199 frames captured from the browser compositor during keyboard play, encoded at 1920×1080 using their capture timestamps. The three 2560×1440 stills preserve the normal combat HUD. This clip covers 5.76 seconds of the opening exchange.
