The images are 2560 × 1440 gameplay screenshots taken in Windows Edge on an NVIDIA RTX 5080. The 8.59-second clip uses 314 timestamped screen frames at 1600 × 900, with the same gameplay session's stereo audio.

A foot contact drives the water rings and the pilgrim's step sound. Each rig computes its stance from its own hip, shin and ankle bones. The gait tests exercise sidestepping, stopping and repositioning with the node transforms read from each shipped GLB. Three-dimensional bamboo strips form the travel hat.
