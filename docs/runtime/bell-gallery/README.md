# 守钟人的雨廊

从山道穿过石狮，第一场决斗在木构雨廊下展开。八根朱漆柱承起灰蓝筒瓦，东侧照壁上刻有白鹭、梅枝与芦苇。开放的西侧引入天光，两盏绢灯给面具和武器留下一道暖边。

以下是同一可玩关卡的定机位截图，分辨率为 2560 × 1440。为便于比较，拍摄脚本让上一版海棠和守钟人停在相同的攻击姿势。带 HUD 的新海棠移动实录见[玉燕海棠](../jade-swallow/)。
